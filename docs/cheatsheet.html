Optional hooks familiar-hooks

Per project. Copy the .familiar folder from the hooks download onto the project, then use → Hooks, or the tool directly. Restart the session after applying. Get the hooks.

HookDoes
Run in the project folderDoes
python .familiar/hooks/install_hooks.py listList the hooks and which are on
python .familiar/hooks/install_hooks.py preview <id>Show exactly what would change
python .familiar/hooks/install_hooks.py apply <id> --yesTurn hooks on (--group guards, --all)
python .familiar/hooks/install_hooks.py remove <id> --yesTurn them off again

The guards are a deterrent, not a security boundary. They run Python around every tool call, so check before installing them on managed work hardware.
