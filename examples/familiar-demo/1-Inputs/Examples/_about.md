# Examples

Reference material showing what good output looks like — style, tone, or structure to match. Not
necessarily related to this project; unlike `Sources/`, these are not facts to synthesize into
project knowledge.

Immutable: familiar reads from these but never edits, rewrites, or moves them. familiar does not scan
this folder on its own — the user points to a specific example when it's relevant ("use this one as
the model"). The ingest/tiered-read rule in `ingest.md` does not apply here.
