# Updates

Drop zone for a new familiar release. To update this project:

1. Download the new zips from the Releases pages: `familiar-workspace-<version>.zip`, and the zip of
   any extension or of the hooks package you also use.
2. Put them in this folder. Zipped or unzipped both work.
3. Run `/system-settings` → Update. It reads them from here, shows what would change, and applies it
   on your yes. Your own edits are kept and every replaced file is backed up.

Nothing in this folder is project content: familiar never ingests, cites or tidies it. Delete the
zips yourself once the update is done; the next update uses the newest copy here either way.
