# Templates

Project-specific blank templates supplied or approved by the user.
familiar uses a template the user selects or a project template placed here. When this folder has
no selected template, familiar reports deck creation unavailable; it never invents a brand template
or searches arbitrary company folders. Copy -> edit -> save to `Drafts`.

Note: unlike the rest of `1-Inputs/`, these are blank assets familiar fills, not source material to
ingest or synthesize — the ingest/tiered-read rule in `ingest.md` does not apply to this folder.
