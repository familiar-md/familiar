# Retrieval and review workers - fallback for a host with no named-subagent dispatch

**This host cannot dispatch the requested named worker.** Load that worker's installed definition
from the core or extension package and perform its contract inline under `bootstrap.md` →
CORE-GROUND. Do not pretend a separate context ran. Two consequences must be explicit:

- Retrieval costs main-context budget that delegation would have saved. Open the section file,
  not the whole library.
- A multi-perspective review runs as sequential personas in one context, so the perspectives are
  not independent. Say so when delivering one.
